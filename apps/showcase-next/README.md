# Form Engine Lab — Expo SDK 58 (Next / Beta)

A standalone React Native showcase for **`@intuitui-labs/form-builder-engine`** running on **Expo SDK 58 beta**, React Native 0.88-rc, and React 19.3.

## Run

```sh
# Start Metro / Expo CLI (use with iOS simulator, Android emulator, or dev client)
pnpm run start

# Web preview
pnpm run web
```

> **Note on Expo Go**: The public Expo Go app distributed on the Apple App Store and Google Play Store only supports stable releases (SDK 57). For SDK 58, use local simulators/emulators (`npx expo start` and press `i` or `a`), web preview (`pnpm run web`), or development builds.

## Verify

```sh
pnpm test
pnpm run typecheck
pnpm run verify
```
